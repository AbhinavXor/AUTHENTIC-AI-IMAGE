# Authentic AI — Professional Motion V12

## Purpose

Replace the decorative V11 orb-and-pill motion treatment with a restrained,
enterprise-grade motion system that preserves the existing Authentic AI light UI.

## Changes

- Removes the large dotted document orb and dark activity pill from artifact generation.
- Uses a clean file icon, stage copy, compact progress markers, subtle activity dots,
  and a restrained progress sweep.
- Replaces assistant thinking/searching/rendering pills with a light inline status.
- Makes the empty conversation composer compact while retaining auto-expansion for text.
- Removes constant composer glow and keeps focus/working feedback subtle.
- Replaces Sherry's decorative launch orb with immediate lightweight progress dots.
- Reduces Sherry launch delay from roughly half a second to 220 milliseconds.
- Preserves result cards, document generation, cancellation, downloads, revisions,
  source fidelity, graph inclusion, and backend behavior.
- Includes mobile tuning and prefers-reduced-motion support.
